# CSS LAB

文化祭予備展示用の、ブラウザ上でCSSを編集してWebサイトの見た目をリアルタイムに変更できる体験型Webサイトです。

## 概要

左側に表示される文化祭サイトのプレビューを見ながら、右側のCSSエディタでCSSを編集できます。

CSSの変更はリアルタイムでプレビューに反映されます。

## 使用技術

* React
* TypeScript
* Vite
* CSS

## 使用方法

### 1. リポジトリを取得

```bash
git clone <repository-url>
cd School_fes_2026
```

### 2. パッケージをインストール

```bash
npm install
```

### 3. 開発サーバーを起動

```bash
npm run dev
```

### 4. ブラウザでアクセス

ターミナルに表示されたURLをブラウザで開きます。

通常は以下のURLです。

```text
http://localhost:5173
```

### 5. CSSを編集

画面右側のCSSエディタにあるコードを変更します。

変更すると、画面左側の文化祭サイトにリアルタイムで反映されます。

### 6. 初期状態に戻す

右上の **Reset** ボタンを押すと、CSSを最初の状態に戻せます。
